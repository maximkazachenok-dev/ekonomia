# Экономия денег

Семейный бюджет, который отвечает на один вопрос: **сколько сегодня можно потратить в магазине**.

**Приложение:** https://maximkazachenok-dev.github.io/ekonomia/
**Код:** https://github.com/maximkazachenok-dev/ekonomia

- Бюджет считается от зарплаты до зарплаты, а не по календарным месяцам.
- **Магазин.** Сумма делится на оставшиеся дни. Потратили меньше — завтра можно больше, потратили больше — завтра меньше. Лимит на сегодня внутри дня не меняется, меняется только «осталось сегодня».
- **Конверты до зарплаты:** бьюти, стрижка, топливо, ремонт авто и любые свои.
- **Копилки с целью.** В конце периода сэкономленное можно одним нажатием отложить в копилку.
- **Общий бюджет на двоих.** Вы и жена вносите траты со своих телефонов и сразу видите записи друг друга.
- **Работает без интернета.** Трата, внесённая в магазине без сети, отправится сама, когда сеть появится.

## 1. Попробовать на компьютере

```bash
python3 tools/serve.py
```

Откройте http://localhost:5173. Если добавить `--pages`, приложение откроется по адресу `/ekonomia/`, как на GitHub Pages. Пока Firebase не подключён, приложение работает в **локальном режиме**: данные хранятся только в этом браузере.

Тесты логики бюджета:

```bash
/System/Library/Frameworks/JavaScriptCore.framework/Versions/Current/Helpers/jsc -m tests/budget.test.js
```

Также их можно запустить в браузере: http://localhost:5173/tests/

## 2. Подключить Firebase (общий бюджет на двоих)

Бесплатного тарифа Spark для семьи хватает с большим запасом. Настройка один раз, около 10 минут.

1. Откройте https://console.firebase.google.com → **Создать проект**.
   - Имя любое, например `ekonomia`.
   - Google Analytics можно выключить.
2. **Build → Authentication** → «Начать» → вкладка **Sign-in method** → **Email/Password** → включить → Сохранить.
3. **Build → Firestore Database** → «Создать базу данных».
   - Регион: `eur3 (europe-west)`.
   - Режим: **production**.
4. Во вкладке **Rules** удалите всё, вставьте содержимое файла [`firestore.rules`](firestore.rules) и нажмите **Publish**.
5. Шестерёнка → **Project settings** → внизу «Your apps» → значок **`</>`** (Web).
   - Придумайте имя приложения. Firebase Hosting не нужен.
   - Скопируйте объект `firebaseConfig`.
6. Вставьте его в [`js/config.js`](js/config.js) вместо `null`:
   ```js
   export const firebaseConfig = {
     apiKey: '...',
     authDomain: '....firebaseapp.com',
     projectId: '...',
     storageBucket: '...',
     messagingSenderId: '...',
     appId: '...',
   };
   ```
   Эти ключи не секретные: они и должны быть видны в браузере. Ваши данные защищают правила из шага 4.
7. После публикации на GitHub (шаг 3): **Authentication → Settings → Authorized domains** → **Add domain** → `ваш-логин.github.io`.

После подключения:
- Первый человек регистрируется и создаёт семейный бюджет.
- В **Настройки → Семья** появится **код приглашения** из 6 символов.
- Второй человек регистрируется под своим email, выбирает «У меня есть код приглашения» и вводит этот код.

> Данные из локального режима в облако автоматически не переносятся. Удобнее всего подключить Firebase до того, как начнёте вести учёт.

## 3. Опубликовать на GitHub (GitHub Pages)

Код хранится на GitHub, а сам сайт бесплатно раздаёт GitHub Pages.

**Уже сделано:** репозиторий `maximkazachenok-dev/ekonomia` создан, GitHub Pages включён. Обновления выкладываются командой `git push`: GitHub CLI установлен в `~/.local/gh` и вход в аккаунт выполнен. Шаги ниже нужны, только если понадобится повторить всё вручную без командной строки, через программу **GitHub Desktop**.

**Один раз:**

1. Зарегистрируйтесь на https://github.com. Запомните логин: он будет частью адреса приложения.
2. Скачайте и установите **GitHub Desktop**: https://desktop.github.com. Откройте программу и войдите в свой аккаунт GitHub.
3. В GitHub Desktop: **File → Add Local Repository…** → выберите папку `Экономия денег` → **Add Repository**. Папка уже подготовлена как репозиторий, в ней есть первая версия.
4. Нажмите **Publish repository**.
   - **Name:** `ekonomia`. Латиницей, это будет частью адреса.
   - **Снимите галочку «Keep this code private».** На бесплатном аккаунте GitHub Pages работает только с открытыми репозиториями. Ваших трат там не будет: в репозитории только код, а данные лежат в Firebase.
   - Нажмите **Publish Repository**.
5. На сайте github.com откройте свой репозиторий `ekonomia` → **Settings** → слева **Pages**.
   - **Source:** «Deploy from a branch».
   - **Branch:** `main`, папка `/ (root)`.
   - Нажмите **Save**.
6. Через 1–2 минуты приложение будет доступно по адресу **`https://ваш-логин.github.io/ekonomia/`**. Адрес также виден в Settings → Pages.
7. Добавьте `ваш-логин.github.io` в Firebase (шаг 2.7).

**Обновить приложение:**
1. В файле [`sw.js`](sw.js) увеличьте `VERSION`, например `v1.0.1`.
2. В GitHub Desktop слева появятся изменённые файлы.
   - Внизу впишите короткое описание и нажмите **Commit to main**.
   - Затем нажмите **Push origin**.
   - Если изменения уже закоммичены (например, это сделал Claude), достаточно нажать **Push origin**.
3. Через 1–2 минуты обновление окажется на сайте. Телефоны получат его при следующем открытии приложения.

**Проверка формул на GitHub.** При каждом обновлении GitHub сам запускает тесты расчёта бюджета. Результат видно во вкладке **Actions** репозитория: зелёная галочка значит, что всё в порядке.

## Как считается дневной лимит

```
лимит на сегодня  = (сумма на период − потрачено до сегодня) / дней до зарплаты
осталось сегодня  = лимит на сегодня − потрачено сегодня
завтра будет      ≈ (остаток на период) / (дней до зарплаты − 1)
```

Пример: на магазин 1000 р. с 10 октября по 10 ноября (31 день).
- **10 октября.** Лимит 32,25. Потратили 20, значит, на 11-е останется 980 / 30 = 32,66.
- **Если 10-го потратили 100**, то на 11-е будет 900 / 30 = 30,00. Перерасход распределяется на оставшиеся дни.

Подсказка «идёте с запасом» или «нужно притормозить» сравнивает сегодняшний лимит с ровным планом (сумма / дней в периоде).

## Устройство проекта

Сборка не нужна: это обычные ES-модули. Preact и Firebase загружаются с CDN, service worker кэширует их для работы офлайн.

```
index.html, manifest.webmanifest, sw.js   — оболочка PWA
css/app.css                                — стили (светлая и тёмная тема)
js/app.js                                  — точка входа, состояние, вкладки
js/config.js                               — ключи Firebase (null = локальный режим)
js/lib/budget.js                           — вся математика бюджета (покрыта тестами)
js/lib/dates.js, money.js                  — даты и деньги (суммы в копейках)
js/data/local.js                           — хранение в браузере
js/data/firebase.js                        — Firestore + вход по email
js/screens/*                               — экраны
js/ui/*                                    — шторки и общие компоненты
firestore.rules                            — правила доступа к данным
tests/                                     — тесты
tools/serve.py                             — локальный сервер (--pages: как на GitHub Pages)
.github/workflows/tests.yml                — автозапуск тестов на GitHub
.nojekyll                                  — GitHub Pages отдаёт файлы как есть
```
